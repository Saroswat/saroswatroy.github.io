# Contributing

This is Saroswat Roy's personal professional portfolio. Small, focused pull requests are preferred.

1. Create a feature branch.
2. Keep evidence-bearing content in `data/portfolio.ts`.
3. Do not add personal or employer-confidential data.
4. Run lint, type checks, tests and the production build.
5. Describe accessibility, content-evidence and visual changes in the pull request.

Project facts require a public repository link or a verifiable local artefact. Certification credential links require an issuer page that names Saroswat Roy.
