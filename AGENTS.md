# Repository instructions

- Use British English in all public copy.
- Treat `data/portfolio.ts` as the source of truth for profile, project, career, education, skill and certification content.
- Do not add project metrics, deployment links, credential links or technologies without repository or issuer evidence.
- Keep the site functional without GitHub API access or third-party JavaScript.
- Preserve keyboard access, visible focus, reduced-motion support and colour contrast.
- Never commit `.env` files, personal addresses, telephone numbers, identity numbers, credentials or employer-internal information.
- Run `npm run lint`, `npm run typecheck`, `npm test` and `npm run build` before proposing a change.
- The bundled Vinext/Sites integration and `.openai/hosting.json` are deployment-critical; do not remove them.
